SETUP

从连接到启动

电脑端负责管理资料，手机端负责实际运行。两端都准备好后，再导入或创建环境。

01

确认手机状态

手机必须是已完成 MD1 系统配置的 Google Pixel，并已安装目标 App。

02

连接电脑端

打开 USB 调试并允许授权。启动 MD1 电脑端，选择手机后读取或导入环境资料。

03

检查并启动

确认平台、国家和代理后保存环境。只有软件明确提示时，才刷新手机运行环境。

P

PAYPAL QUICK CHECK

PayPal 保存或启动失败时，先看这 4 项

官方 App 已安装并打开过一次；包名为 com.paypal.android.p2pmobile；电脑端已重新读取手机应用列表；PayPal 没有和其他受控业务 App 绑定在同一个环境里。

查看排查说明 →

FAQ

常见问题

遇到保存被拦截时，手机端会显示具体校验原因，并提供“复制错误”按钮，方便直接发给支持人员。

为什么 PayPal 环境保存会被阻断？

同一环境不能同时绑定多个受控业务 App。请确认 PayPal 使用独立环境；如果提示中列出了冲突包名，先移除其他业务 App 或新建一个 PayPal 环境。

手机端看不到 PayPal 怎么办？

安装官方 PayPal App 后，重新打开一次，再在电脑端重新连接或刷新手机应用列表。手机端目标包名应为 com.paypal.android.p2pmobile。

保存失败怎么把错误发给支持人员？

在手机端保存结果弹窗中点击“复制错误”，再粘贴到微信发送。诊断文本只包含环境 ID、错误说明和校验步骤，不包含账号、Cookie、Authorization 或业务数据。

普通 Pixel 手机可以直接使用吗？

不可以。当前手机端只支持已经由 MD1 支持人员完成系统配置的 Google Pixel 系列手机，请先确认机型和配置安排。

macOS 首次打不开 App 怎么办？

当前测试交付包使用 macOS 临时签名，首次启动请在 Finder 中右键 App 并选择“打开”。不要把 Windows 的 EXE、ADB 或 scrcpy 目录复制到 Mac。
