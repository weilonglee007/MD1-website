# MD1 官网

这是 MD1 的静态产品介绍页，面向需要使用 MD1 环境管理器的客户。

页面介绍软件功能、支持平台、使用流程、在线更新通道和下载方式。

完整客户使用指南：

- `guide.html`：在线版操作指南
- `guides/MD1系统使用指南-图文版-2026-08-31.docx`：当前可下载的 Word 图文版
- `guides/MD1系统使用指南-图文版-2026-08-27.docx`：旧版 Word 图文版

指南内容覆盖手机连接、环境创建、批量导入、模板和代理、MD1 浏览器、同步启动、投屏、2FA、手机状态刷新、测试/正式更新通道、在线和手动组件更新、清理和常见问题。

页面下载入口指向公开的 `weilonglee007/MD1-website` 最新版本发布页，官网地址为：

- <https://md1.online/>

- macOS Apple Silicon 完整包
- macOS 资源更新包
- Windows x64 完整包
- 手机端更新文件

手机端更新由电脑端管理器完成，支持在线更新和原来的本地手动更新。

- 当前主要支持 Google Pixel 系列手机，手机需要先寄送给 MD1 支持人员完成系统配置。
- 客户默认使用正式更新；内部测试手机从左侧“测试更新”入口输入密码后测试，通过后再将同一版本发布到正式通道。
- 联系方式：微信 `M1browsers`。
